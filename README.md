# Neon Breaker

Un rompebloques clásico hecho con HTML, CSS y JavaScript puro.

## Jugar

Abrí `index.html` en un navegador. No requiere instalación.

- Flechas o `A`/`D`: mover la paleta
- Espacio: lanzar la pelota o pausar
- Mouse/táctil: mover la paleta; tocar para lanzar

El juego tiene un solo nivel, con bloques que forman «CTC». Cada bloque suma 100 puntos. Al perder las tres vidas, el puntaje determina el premio:

- Hasta 2000 puntos: una golosina.
- De 2001 a 3000: un pegotín.
- De 3001 a 3500: un llavero.
- De 3501 a 4000: una lapicera.

Al romper todos los bloques, completás el nivel y ganás todos los premios. También hay récord local y sonido.
