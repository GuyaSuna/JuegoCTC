# Neon Breaker

Un rompebloques clásico hecho con HTML, CSS y JavaScript puro.

## Jugar

Abrí `index.html` en un navegador. No requiere instalación.

- Flechas o `A`/`D`: mover la paleta
- Espacio: lanzar la pelota o pausar
- Mouse/táctil: mover la paleta; tocar para lanzar

Incluye niveles progresivos, vidas, puntaje, récord local y sonido.
